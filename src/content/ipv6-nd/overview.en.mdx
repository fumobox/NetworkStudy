## Getting on the LAN without DHCP

An IPv6 host can configure itself. The router only announces the prefix of the LAN; the host builds its own address, checks that nobody else uses it, and finds its neighbors with **Neighbor Discovery**, a set of ICMPv6 messages that replaces ARP and much of DHCP.

| Message | Sent to | Purpose |
|---|---|---|
| Router Solicitation (RS) | `ff02::2` (all routers) | “Is there a router?” |
| Router Advertisement (RA) | `ff02::1` (all nodes) | the prefix, the default router, DNS servers |
| Neighbor Solicitation (NS) | a solicited-node group | “Who has this address?” or “Is anyone using it?” |
| Neighbor Advertisement (NA) | the asker, or all nodes | “It is me, here is my MAC address” |

## The steps

1. **Link-local address**: the host combines `fe80::/64` with its interface ID. It needs no router and works only on the LAN.
2. **Duplicate address detection (DAD)**: the address is *tentative* until the host has asked, from the unspecified address `::`, whether anyone already uses it. If nobody answers within a second, it becomes *preferred*.
3. **RS and RA**: the host asks for routers; the router answers with the prefix. The A flag allows **SLAAC** (stateless address autoconfiguration), and the M and O flags say whether DHCPv6 is needed.
4. **Global address**: prefix + interface ID, checked with DAD again.
5. **Address resolution**: to send on the LAN, the host asks with an NS for the neighbor’s MAC address and keeps the answer in its **neighbor cache**.

## Multicast instead of broadcast

IPv6 has no broadcast. An NS goes to the **solicited-node multicast address** of the target (`ff02::1:ff` and the last 24 bits), which only a few devices join. The NICs of all other devices drop the frame without bothering the rest of the system.

## What to look for in the walkthrough

- The address table of the PC: `tentative` → `preferred`, and later a second, global address.
- Which devices accept each multicast and which ones drop it.
- The neighbor cache: `STALE` from the RA, then `INCOMPLETE` → `REACHABLE` for PC 2.
- In the “What if…” options: a duplicated address, and a LAN without a router.

## Try it yourself

```sh
ifconfig en0 inet6
ndp -an
```

Trimmed output (macOS 26, 2026-09-29). The global prefix and the MAC addresses are replaced with the values used in this theme (2001:db8:1::/64).

```
$ ifconfig en0 inet6
inet6 fe80::1c38:fd23:1cb8:916d%en0 prefixlen 64 secured scopeid 0xb
inet6 2001:db8:1:0:c35:c0f1:eb7c:c74e prefixlen 64 autoconf secured
inet6 2001:db8:1:0:94b9:2864:3e2e:f8a9 prefixlen 64 deprecated autoconf temporary
inet6 2001:db8:1:0:c1a:4e0f:fe40:740a prefixlen 64 autoconf temporary
$ ndp -an
Neighbor                    Linklayer Address  Netif Expire    St
2001:db8:1:0:4d1:e319:1180:84ff 00:00:5e:00:53:14  en0 21h33m13s S
2001:db8:1:0:c35:c0f1:eb7c:c74e 00:00:5e:00:53:0a  en0 permanent R
```

- The `fe80::` address is the link-local one. The others were made by SLAAC (`autoconf`) from the prefix in the Router Advertisement. macOS picks random interface IDs instead of EUI-64: a `secured` address stays the same on this network (RFC 7217), and `temporary` ones change regularly for privacy (RFC 8981). An older temporary address is `deprecated`: still valid, but no longer used for new connections.
- `ndp -an` is the neighbor cache. `St` is the state: R (REACHABLE) and S (STALE); `permanent` rows are the computer’s own addresses.
- On Linux, `ip -6 addr` and `ip -6 neigh` show the same. In Wireshark, the display filter `icmpv6.type >= 133 && icmpv6.type <= 137` shows the Neighbor Discovery messages (RS, RA, NS, NA, Redirect).

## About this page

The interface ID is made from the MAC address (EUI-64) so that the addresses are easy to follow; most operating systems now use random interface IDs instead (RFC 7217, RFC 8981). MLD (how hosts announce the groups they join), MLD snooping in switches, the random delays before DAD and RS, periodic RAs, DHCPv6, and the DELAY and PROBE states of the neighbor cache are left out. How PC 2 configured its own address is not shown. See also the IPv6 address theme for the notation and the kinds of addresses.
