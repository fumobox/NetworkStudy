## IPv6 アドレスの書き方

IPv6 アドレスは 128 ビットで、IPv4 の 4 倍の長さ。16 ビットずつ 8 つのグループに分け、16 進数でコロンで区切って書く。`2001:0db8:0001:0000:0200:5eff:fe00:530a`。短くする規則が 2 つある。

- グループの**先頭の 0** は省ける。`0db8` → `db8`、`0000` → `0`。
- 0 のグループが続くところを **1 か所だけ** `::` にできる。2 か所で使うと、どこに何個の 0 があるかわからなくなる。

同じアドレスをいくつもの書き方で書けるので、RFC 5952 は 1 つの形を推奨している。小文字で、先頭の 0 を省き、2 つ以上続く 0 のグループのうちいちばん長いところ（同じ長さなら最初）を `::` にする。

## プレフィックスとインターフェース ID

IPv4 と同じく、アドレスにはネットワークの部分があり、これを**プレフィックス**と呼んでスラッシュで書く（`2001:db8:1::/64`）。LAN のプレフィックスはほぼいつも /64 で、残りの 64 ビットが機器の**インターフェース ID**。

## アドレスの種類

| プレフィックス | 種類 | 使い道 |
|---|---|---|
| `::1/128` | ループバック | 自分自身 |
| `fe80::/10` | リンクローカル | 1 つのリンクの中だけ。どのインターフェースにもある |
| `fc00::/7` | ユニークローカル | 組織の中。IPv4 のプライベートアドレスにあたる |
| `2000::/3` | グローバルユニキャスト | インターネット |
| `ff00::/8` | マルチキャスト | 機器のグループ |
| `2001:db8::/32` | 文書用 | 本やマニュアルの例 |

IPv6 には**ブロードキャストがない**。リンクのすべての機器に送るパケットはマルチキャストのグループ `ff02::1` 宛てにする。近隣探索は、各質問を見る機器が少なくて済むよう**要請ノードマルチキャストアドレス**（`ff02::1:ff` と、アドレスの下位 24 ビット）を使う。

## MAC アドレスからのインターフェース ID

48 ビットの MAC アドレスからインターフェース ID を作れる（**EUI-64**）。中央に `ff:fe` を挟み、最初のバイトの U/L ビットを反転する。わかりやすく、ルーターでは今も使うが、ID が変わらないとどこでもその機器だと見分けられてしまう。そのため今は、ほとんどの OS がランダムなインターフェース ID を使う。

- 例のボタン。グローバルアドレス、それと対になるリンクローカルアドレス、ループバック、マルチキャスト、IPv4 射影アドレス。
- アドレスを長い形で入力して推奨の表記を見る。プレフィックス長を変えてビットを見る。
- MAC アドレスからリンクローカルアドレスを作る。
